# ⚡ خطوات سريعة - 10 دقائق فقط!

## الخطة:

### 1️⃣ MongoDB Atlas (3 دقائق)
```
1. mongodb.com/atlas → Try Free
2. Build Database → FREE → Create
3. Security → Database Access → Add User (اسم + كلمة سر)
4. Security → Network Access → Allow Anywhere
5. Database → Connect → Copy URL
```

### 2️⃣ Discord Bot (3 دقائق)
```
1. discord.com/developers/applications → New App
2. Bot → Add Bot → Reset Token → Copy
3. Bot → Enable all 3 Intents
4. OAuth2 → URL Generator → bot + applications.commands + Administrator
5. Copy invite URL → Open it → Add to your server
```

### 3️⃣ GitHub (2 دقيقة)
```bash
git init
git add .
git commit -m "first"
# ارفعه على GitHub
```

### 4️⃣ Render.com (2 دقيقة)
```
1. render.com → Sign up with GitHub
2. New + → Web Service → اختر المشروع
3. Environment: Node
4. Build: npm install
5. Start: npm start
6. Plan: Free
7. أضف Environment Variables:
   - DISCORD_TOKEN
   - CLIENT_ID
   - MONGODB_URI
   - DASHBOARD_URL
8. Deploy!
```

### 5️⃣ UptimeRobot (اختياري - 1 دقيقة)
```
1. uptimerobot.com → Sign up free
2. Add Monitor → HTTP
3. URL: https://your-app.onrender.com
4. Interval: 5 minutes
```
