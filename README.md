# 🎫 ALQUEEN Ticket Bot

بوت تكت دسكورد احترافي مع لوحة تحكم ويب متكاملة

## ✨ المميزات

### 🤖 بوت دسكورد
- نظام تكت متطور مع فئات متعددة
- إدارة شاملة للتكتات (إنشاء، إغلاق، إعادة فتح، حذف)
- نظام صلاحيات متقدم
- حفظ نسخ من المحادثات (Transcripts)
- إحصائيات تفصيلية
- نظام تقييم الدعم

### 🌐 لوحة تحكم ويب
- إحصائيات حية ومباشرة
- إدارة التكتات من المتصفح
- مراقبة أداء البوت
- تنبيهات فورية
- تقارير مفصلة

## 📦 التثبيت

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد البيئة
cp .env.example .env
# قم بتعديل ملف .env بمعلوماتك

# 3. تشغيل البوت
npm start
```

## 🚀 الاستخدام

1. أضف البوت إلى سيرفرك
2. استخدم الأمر `/setup` لإنشاء نظام التكت
3. زُر لوحة التحكم على `http://localhost:3000`

## 📝 الأوامر

- `/setup` - إعداد نظام التكت
- `/ticket` - إنشاء تكت جديد
- `/close` - إغلاق التكت
- `/add` - إضافة عضو للتكت
- `/remove` - إزالة عضو من التكت
- `/stats` - عرض الإحصائيات

## 🔧 المتطلبات

- Node.js 18+
- MongoDB
- Discord Bot Token
